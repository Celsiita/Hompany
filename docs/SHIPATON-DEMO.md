# Guion vídeo Shipaton (≤ 2 min)

Grabar en dispositivo/emulador con seed limpio (`npm run db:reset`) y, si es posible, `EXPO_PUBLIC_REVENUECAT_API_KEY` (Test Store).
Repite el tutorial una vez (Ajustes → Ver tutorial) o úsalo al inicio para enseñar interactividad.

| Tiempo | Qué mostrar | Qué decir (opcional VO) |
|--------|-------------|-------------------------|
| 0–12 s | Login marca **HOMPANY** + tour Mico (1–2 pasos) | “HOMPANY: convivencia gamificada para pisos de estudiantes.” |
| 12–30 s | Feed: salud (cumplimiento %) + ranking + cuentas; toca `?` | “Estado del piso, reputación y deudas. La ayuda explica cada bloque.” |
| 30–45 s | Agenda: leyenda azul/cielo/ámbar + lista | “El calendario diferencia tus tareas, las de compañeros y los gastos.” |
| 45–55 s | Piso: Wi‑Fi / reglas | “Datos del hogar aparte, sin ensuciar el feed.” |
| 55–75 s | Tareas: chip Tuya/Compañero + Mico (aprobar/cambio) / campanita | “Prueba con foto; ves al instante qué es tuyo.” |
| 75–95 s | Gastos: chip Debes/Tú pagaste + saldar | “Quién debe a quién, sin drama.” |
| 95–115 s | Ajustes → Ver HOMPANY Plus → pack | “Plus opcional (packs). RevenueCat en el código.” |
| 115–120 s | Invite code / QR | “Invita al piso y listo.” |

Subir a YouTube/Vimeo público. Sin música con copyright.
