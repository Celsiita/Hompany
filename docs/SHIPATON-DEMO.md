# Guion vídeo Shipaton (≤ 2 min)

Grabar en dispositivo/emulador con seed limpio (`npm run db:reset`) y, si es posible, `EXPO_PUBLIC_REVENUECAT_API_KEY` (Test Store).
Repite el tutorial una vez (Ajustes → Ver tutorial) o úsalo al inicio para enseñar interactividad.

| Tiempo | Qué mostrar | Qué decir (opcional VO) |
|--------|-------------|-------------------------|
| 0–12 s | Login: toca **Demo local** → Entrar + tour Mico (1–2 pasos) | “HOMPANY: convivencia gamificada para pisos de estudiantes.” |
| 12–30 s | Inicio → Feed: estado + ranking; toca **Próximamente** | “Estado del piso. Plus: buscar piso o gente con reputación.” |
| 30–45 s | Agenda: `?` junto al mes → leyenda; lista del día | “El calendario diferencia tuyas, compañeros, debes y te deben.” |
| 45–55 s | Tab Piso: silencio + **Próximamente** + Wi‑Fi | “Vida del hogar; matching también desde aquí.” |
| 55–75 s | Tareas: chip Tuya/Compañero + aprobar/cambio / campanita | “Prueba con foto; ves al instante qué es tuyo.” |
| 75–95 s | Gastos: chip Debes/Tú pagaste + saldar | “Quién debe a quién, sin listas compartidas.” |
| 95–115 s | Ajustes → Ver HOMPANY Plus | “Plus cableado con RevenueCat; matching en camino.” |
| 115–120 s | Invite code / QR | “Invita al piso y listo.” |

Subir a YouTube/Vimeo público. Sin música con copyright.
